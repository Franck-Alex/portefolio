## Lancer le portfolio
Décompressez l'archive puis ouvrez `index.html` dans un navigateur.
Aucun serveur PHP ou base de données n'est nécessaire pour cette première version.

## À personnaliser avant publication
- Remplacer `votre.email@example.com` par votre adresse professionnelle.
- Remplacer les liens LinkedIn et GitHub `#` par vos profils réels.
